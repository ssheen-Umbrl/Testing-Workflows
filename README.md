# Testing-Workflows

Harness for testing the data-bigquery-dbt deploy workflows (PRC-252).
`.github/workflows/*.yml` are generated by `transform.py` from the real
workflows: orchestration is kept verbatim, GCP/dbt steps are stubs controlled
by files in `test-control/` (`<key>-fail`, `<key>-sleep`).

`.github/actions/` is copied from the real repo as-is (composite actions run
unchanged).
